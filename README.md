Senja Canyon — an original sunset canyon stunt racer built for the make.fun best flight game bounty. Fly a stunt plane through glowing rings in a winding red-rock canyon at golden hour: throttle discipline, near-miss bonuses, rock spires to dodge, fuel that turns each sortie into decisions, and three heats of rising difficulty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Steer with arrows / WASD, throttle with W/S (or E/Q), Space to start, P to pause. Mouse drag steers too.
